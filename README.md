# Math-Review

A simple 6th grade single-player math review quiz game.

## Play the game

Open `index.html` in your browser to start the quiz.

## Game features

- Single-player quiz
- Questions across ratios, percents, LCM/GCF, fractions, expressions, equations, coordinate plane, area, statistics, and integers
- Score tracking and final result

## Files

- `index.html` — game interface
- `style.css` — game styling
- `script.js` — quiz logic and questions
